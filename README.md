# 🚀 Sales Forecasting using Time Series Analysis (ARIMA & LSTM)

Predicting future sales trends by combining classical statistical models with deep learning techniques.

---

## 📌 Overview
This project focuses on **time series forecasting** of sales data using both traditional and deep learning approaches. It implements:

- **ARIMA (AutoRegressive Integrated Moving Average)** for statistical modeling  
- **LSTM (Long Short-Term Memory)** for deep learning-based forecasting  

The objective is to analyze historical trends and predict future sales while comparing the performance of both models.

---

## 🎯 Objectives
- Understand time series data (trend, seasonality, patterns)
- Build and implement ARIMA model
- Build and implement LSTM model
- Compare performance using evaluation metrics
- Visualize actual vs predicted results

---

## 🛠️ Tech Stack
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Scikit-learn  
- TensorFlow / Keras  
- Statsmodels  

---

## 📊 Dataset
- Inbuilt **AirPassengers dataset**
- Monthly time-series data
- Converted into proper datetime indexed format for forecasting

---

## ⚙️ Project Workflow

### 1. Data Preprocessing
- Load dataset  
- Convert to time series format  
- Set datetime index  

### 2. Exploratory Data Analysis (EDA)
- Plot time series  
- Identify trends and seasonality  

### 3. ARIMA Model
- Apply differencing  
- Train ARIMA model  
- Forecast future values  

### 4. LSTM Model
- Normalize data using MinMaxScaler  
- Create sequences for time series  
- Train LSTM neural network  

### 5. Evaluation
- Compare models using **RMSE**
- Plot predictions vs actual values  

---

## 📈 Results
- **ARIMA** performs well for linear patterns  
- **LSTM** captures complex temporal dependencies  
- Comparison highlights strengths of both approaches
